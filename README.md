### 🔍 [InternPulse — AI-Powered Internship Tracker](https://github.com/chaitanyakumarAI/Intern-Pulse)
> Automated pipeline: Gmail (read-only OAuth) → Gemini classification & extraction → Supabase PostgreSQL → Telegram alerts
- 🧠 Three-tier classifier: deterministic relevance filter → Gemini JSON-mode extraction with schema validation → keyword/regex fallback
- 🛡️ API-key rotation, retry with backoff, circuit breaker, and a status state machine that blocks stale regressions
- 🔁 Duplicate-free sync via Gmail-ID tracking and canonical company keys; rules-first scam detector with LLM risk assessment
- 📈 Extraction accuracy **40% → 95%+**; **75-test** offline pytest suite and an eval harness (precision, recall, macro-F1)
- 📊 Next.js Kanban dashboard; daily runs on GitHub Actions
- `Python` `Gemini 2.5 Flash` `Supabase` `PostgreSQL` `Gmail API` `Next.js` `GitHub Actions`
